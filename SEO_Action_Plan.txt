PHASE 3 — ON-PAGE OPTIMIZATION (Week 3–6)
================================================================================

STEP 3.1  Title Tags
--------------------------------------------------------------------------------
[ ] Unique title for each page (50–60 characters)
[ ] Primary keyword near front
[ ] Include location (Dubai, UAE) where relevant
[ ] Brand at the end: " | Al Kabir Machinery Rentals"

STEP 3.2  Meta Descriptions
--------------------------------------------------------------------------------
[ ] Compelling 140–160 character descriptions
[ ] Include primary keyword + CTA
[ ] Unique for every page

STEP 3.3  Headings (H1–H6)
--------------------------------------------------------------------------------
[ ] One H1 per page (matches search intent)
[ ] H2s structured around subtopics & questions (AEO)
[ ] Keyword variations in H2/H3

STEP 3.4  Content Optimization
--------------------------------------------------------------------------------
[ ] Keyword prominence: primary keyword in first 100 words
[ ] Keyword density: 1–2% (natural, no stuffing)
[ ] LSI / semantic keywords throughout
[ ] Minimum content length: 800–1500 words on service pages
[ ] Add tables, bullet points, comparison sections

STEP 3.5  URL Optimization
--------------------------------------------------------------------------------
[ ] Short, descriptive, keyword-rich URLs
[ ] Hyphens (not underscores)
[ ] Lowercase, no special chars
[ ] Example: /boom-lift-rental-dubai/

STEP 3.6  Image Optimization
--------------------------------------------------------------------------------
[ ] Descriptive filenames (boom-lift-rental-dubai.jpg)
[ ] Alt text with keywords (descriptive, not stuffed)
[ ] Compressed file sizes
[ ] WebP format
[ ] Add image dimensions (width/height)

STEP 3.7  Internal & External Linking
--------------------------------------------------------------------------------
[ ] 3–5 contextual internal links per page
[ ] Anchor text variations (avoid exact-match overuse)
[ ] 1–2 outbound links to authoritative sources
[ ] Add nofollow where appropriate
